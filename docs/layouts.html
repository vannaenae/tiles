Try the layouts

Pick a screen and a layout, then move the windows around yourself. It runs the same layout maths as the app.


Click a window to focus it. Drag one onto another to swap them. Double-click to make it the main window.

The layouts

Dwindle
Each new window splits the remaining space, along the longer side. A good default.
Master & Stack
One main window on the left, the rest stacked on the right. Wide Master puts the main window on top instead.
Center Stage
The main window in the middle with the others on both sides. Built for ultrawide screens.
Columns, Rows and Thirds
Equal columns, equal rows, or two thirds plus one third.
Grid
Every window gets an equal share.
Scrolling
Windows keep their own width in a row wider than the screen. Focus one and the row slides to it.
Monocle
Every window fills the screen; flip between them.
Float and Snap
Windows stay where you put them. Drag one to a screen edge to snap it to half or a quarter.
