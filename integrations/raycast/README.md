# Tiles for Raycast

Raycast script commands for every everyday Tiles action: layouts, scenes, Focus, floating and workspaces.

1. In Raycast, open **Settings → Extensions → Script Commands → Add Directories**.
2. Choose this `integrations/raycast` folder (or copy it anywhere first).
3. Search Raycast for "Tiles", or give any command a hotkey or alias.

Each script just opens a `tiles://` link, so the same commands work from Alfred, Shortcuts, skhd or a terminal (`tiles <command>`). Run `tiles --help` for the full list.
